## Requirements

- PHP 8.2 or higher
- Filament 4.0 or higher

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/filament-refresh-sidebar
```

## Development

You can run code analysis and formatting using the following commands:

```bash
# Run static analysis
composer analyse

# Format code
composer format
```
